A small, native home
for your terminal agents.

Run a dozen Claude Code and Codex sessions side by side, see at a glance which one needs you, and pick up any of them after a quit, an update or a crash.

Install View on GitHub

Who needs you?

Every tab has a dot: working, needs you, or done. A banner when an agent waits on you, and a click takes you straight there. No setup.

Tabs that don't die

Each tab's shell runs in its own tiny holder process. Quit, update or crash, and every agent keeps going; the window comes back to them.

A viewer above the chat

⌘-click any path or link an agent prints: Markdown, HTML, PDFs, images, video, diffs and code open right above the conversation, with back and forward.

Workstreams

Agents keep a shared record of each piece of work through an MCP server: overview, rules, memory, questions for you, progress and files, beside the chat and back after every compaction.

Native and light

SwiftUI and AppKit, no Electron. Under 100 MB of memory with a few groups loaded, under 1% CPU when idle. Builds with just the Command Line Tools.

Make it yours

Native extensions in Swift for anything deep; JSON plugins for widgets, link rules, themes and palettes, no build needed.

Install

macOS 14 or later, the Xcode Command Line Tools (xcode-select --install) and claude or codex on your PATH.

git clone https://github.com/AgentDE/agentde && cd agentde
make signing    # once, so macOS remembers your permission answers
make install    # about 4 minutes the first time

The first build clones the extensions next to the repo. Run make install again to update; your tabs keep running.

The pieces

agentdeThe app: groups, tabs, agent status, the viewer, search, the extension API
workstream-mcpThe MCP server behind workstreams. Works with plain Claude Code or Codex too, no app needed
agentde-workstreamsThe workstream panel beside each chat, and the Usage widget
agentde-widgetsThe sidebar widget spot, the Calendar widget, and widgets from JSON plugins
agentde-linearLinear tickets in workstreams, and a widget with your open issues
