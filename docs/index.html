Status at a glance

Three colors. You always know.

No setup and no screen scraping: AgentDE reads Claude Code's own session registry, and any agent with hooks can report in.

working

The agent is busy. Leave it be.

needs you

A question or a permission prompt. A banner, a sound, and one click takes you there.

done

Finished while you were elsewhere. It stays blue until you look.

Built around the agent

Everything an agent session needs. Nothing it doesn't.

⌘J · ⌃Tab

Get to the right agent

⌘J jumps to the next agent that needs you. ⌃Tab flips between your busy agents, most recent first, across every project. Yes, alt-tabbing is fully supported.

quit · update · crash

Tabs that don't die

Each tab's shell runs in its own tiny holder process. Quit, update or crash, and every agent keeps going. The window comes back to them.

⌘-click

A viewer above the chat

⌘-click any path an agent prints and it opens right above the conversation, at the line it named: Markdown, HTML, PDFs, images, video, diffs and code.

MCP

Workstreams

Agents keep a shared record of each piece of work: overview, rules, memory, questions for you, progress and files. It sits beside the chat and comes back after every compaction.

⌘D · drag

Two at once

Drag a tab onto the chat to see two agents side by side, or split any way you like. The side panel shows the tab's files and changes.

vibe code it

Make it yours

Nine themes, JSON plugins for widgets, link rules and themes, native extensions in Swift. Or point your agent at the source: it comes with notes for agents and a map of the code.

Bring your agent

Compatible with any agent.

Anything that runs in a terminal runs in a tab. Claude Code and Codex are built in, with their own tools in the chat's corner (rewind, compact, fork, restart); any other agent can report its status through hooks, and plugins add more.

Get it running

Two commands.

1. Install

Homebrew, or the zip: drag AgentDE to Applications. Tabs need claude or codex on your PATH.

brew install --cask agentde/tap/agentde

2. Register workstreams (once)

Adds the workstream MCP server and its hooks to Claude Code and Codex. Without --yes it only shows what it would change.

/Applications/AgentDE.app/Contents/Resources/register-workstream.sh --yes

Or build it yourself

macOS 15.6+ with the Xcode Command Line Tools 26 or newer. No Xcode needed.

git clone https://github.com/AgentDE/agentde && cd agentde
make signing && make install   # about 4 minutes the first time
make register-workstream YES=1
